# Markdown Notes

This is normal text. It is written without any signs or symbols.

For changing the paragraph you have to leave an empty line.

For changing the line only leave 2 spaces on the previous line.  

These normal lines are paragraphs in HTML.

# H1 Heading

For making an H1 heading you have to add 1 "#" hashtag.

## H2 Heading

For making H2 heading you have to add 2 "#" hashtags.

### H3 Heading

Like this, as many hashtags you will type, the size will become smaller.

###### Smallest Heading

This is the smallest heading we can use in Markdown by entering 6 hashtags.
